# Overview

Welcome to Simple Automation for Beginners. This is a beginner's guide to safe,
everyday automation using tools you already have and tiny scripts you can read
end to end.

## Who this is for

You don't need to be a programmer. You don't need to have used the command
line before. If you can copy and paste, you can use this manual.

It's written for anyone who wants their computer to do a little less drudgery:
organizing messy folders, repeating tasks, getting reminded about bills or
appointments, and scheduling things to run automatically. Plain English, step
by step, never condescending.

## What's in the manual

| Guide | What it does |
|-------|-------------|
| [Safety first](safety.md) | The rules to follow before you automate anything |
| [Organizing files](file-organization.md) | Sort a messy folder into type-based subfolders |
| [Repeating tasks](repeating-tasks.md) | Run a command again and again on a timer |
| [Email reminders](email-reminders.md) | Get reminded when something is due |
| [Scheduling](scheduling.md) | Set tasks to run automatically with cron / Task Scheduler |

Each guide has a matching script in `scripts/`. Every script defaults to a
non-destructive preview (dry-run) and works on copies by default; none touches
your originals unless you explicitly ask.

## Printable worksheet

There's a printable checklist in `static/checklist.html`. Open it in your
browser and print it (Letter size) to tick off each step by hand.
