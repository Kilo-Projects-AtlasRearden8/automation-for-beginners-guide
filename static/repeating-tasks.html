What this does

scripts/repeat_task.py runs a command you give it, every N seconds, up to M times (or forever if you don’t set a limit). It defaults to dry-run: it prints the schedule without running anything, so you can see exactly what will happen before anything runs.

Step 1: Preview the schedule

python3 scripts/repeat_task.py "echo hello" --every 10 --times 3

This prints what it would run, every 10 seconds, 3 times — without executing anything.

Step 2: Run for real

python3 scripts/repeat_task.py "echo hello" --every 10 --times 3 --apply

The command runs immediately, then again every 10 seconds, 3 times total. Press Ctrl-C to stop early.

Options

  • --every N — seconds between runs (default 60)
  • --times M — stop after M runs (default: repeat forever)
  • --apply — run the command for real (default is preview only)

Examples

Repeat a backup script every hour, 4 times:

python3 scripts/repeat_task.py "python3 my_backup.py" --every 3600 --times 4 --apply
